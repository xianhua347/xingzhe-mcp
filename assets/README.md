# App icon

Original artwork generated with the built-in Image Gen tool for this independent cycling-data assistant.

- `icon-source.png`: generated master.
- `icon.png`: 256 × 256 palette PNG for ChatGPT, below its 10 KB upload limit.
- `icon-xingzhe.png`: 1024 × 1024 PNG for the Xingzhe OAuth application.

Prompt: Create an original square cycling-data assistant icon with a dark plum bicycle and three ascending cream data nodes on a warm orange background. Use simple, readable geometric shapes and generous margins. No text, Chinese characters, official brand marks, blue-white palette, watermark, or mockup. Keep the entire background opaque and edges clean.

The design deliberately avoids the official Xingzhe mark. Image Gen created and refined the artwork; Sharp resized and encoded the upload files.
